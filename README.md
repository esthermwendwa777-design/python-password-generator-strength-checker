# Python Password Generator & Strength Checker

## Project Overview
This project is a beginner-friendly Python application that generates random passwords and evaluates password strength based on different security requirements.

## Features
- Generates random passwords using Python's `secrets` module.
- Allows users to specify password length.
- Checks password strength.
- Evaluates uppercase and lowercase letters, numbers, and special characters.
- Assigns a password strength score out of 5.
- Provides an interactive menu.

## Technologies Used
- Python 3
- Secrets module
- String module

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run:

```bash
python password_generator.py
```

## Project Status
Currently under development. Additional features, input validation, and improved password-strength analysis will be added.
